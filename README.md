# Isagog Ontologies

Isagog ontologies provide a shared vocabulary for describing entities, events,
information and their relationships. They support knowledge representation,
text analysis and conversational AI.

[Documentation](https://ontology.isagog.com/en/) ·
[Documentazione in italiano](https://ontology.isagog.com/it/) ·
[Explore the ontologies](https://ontology.isagog.com/en/explorer/)

| Ontology | Scope | Download |
| --- | --- | --- |
| **Core** | Foundational concepts for entities, events, agents, information, signs and qualities. | [core.ttl](https://ontology.isagog.com/core.ttl) |
| **Agents** | Speech acts, conversations and the aspects remembered about conversation participants. | [agents.ttl](https://ontology.isagog.com/agents.ttl) |
| **Frames** | Semantic frames, participant roles and the lexical expressions that evoke them. | [frames.ttl](https://ontology.isagog.com/frames.ttl) |

Agents and Frames extend Core. The ontologies include labels and explanatory
text in English and Italian.

Previous versions are available in the [ontology collection](ontologies/).
Published distributions are listed in [Releases](https://github.com/Isagog/isagog-ontology/releases).
